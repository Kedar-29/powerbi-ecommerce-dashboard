# 📊 E-Commerce Sales Dashboard

An interactive Business Intelligence dashboard designed to analyze and monitor e-commerce sales performance. This project focuses on tracking key performance indicators (KPIs), identifying trends, and enabling data-driven decision-making through dynamic visualizations.

---

## 🚀 Project Overview

This dashboard provides insights into:

- Total Revenue
- Total Profit
- Quantity Sold
- Average Order Value (AOV)
- Monthly Profit Trends
- State-wise Sales Distribution
- Category & Sub-category Performance
- Payment Mode Analysis

The dashboard allows users to filter data by quarter and drill down into specific segments using interactive slicers.

---

## 📈 Key Features

- KPI Cards for quick performance monitoring
- Dynamic filtering using slicers (Quarter, Category, Payment Mode)
- Profit trend analysis by month
- State-wise sales comparison
- Customer-level revenue insights
- Category and sub-category performance breakdown
- Clean and business-friendly UI design

---

## 🛠️ Technologies Used

- Power BI / Excel

- Data Cleaning & Transformation
- Data Visualization Techniques
